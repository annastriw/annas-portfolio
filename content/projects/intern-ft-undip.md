# Internship - Tim Developer IT Fakultas Teknik Universitas Diponegoro

## Snapshot

- **Organisasi:** Fakultas Teknik Universitas Diponegoro
- **Tim:** Developer IT
- **Peran:** Developer IT Intern
- **Periode:** Agustus - September 2025
- **Durasi:** 2 bulan
- **Primary Tool:** Figma
- **Fokus:** UI/UX Design, Interactive Prototyping, dan User Documentation

## Ringkasan

Berkontribusi sebagai Developer IT Intern pada Tim Developer IT Fakultas Teknik Universitas Diponegoro dengan fokus pada perancangan pengalaman pengguna, interactive prototyping, dan dokumentasi sistem.

Selama internship, terlibat dalam pengerjaan dua sistem utama, yaitu SITEDI dan SIPERPUS FT UNDIP.

Pekerjaan mencakup perancangan UX, pembuatan interactive prototype menggunakan Figma, penyusunan user flow, information architecture, navigasi, konsistensi layout, serta dokumentasi penggunaan sistem.

Selain kegiatan perancangan, menyusun Buku Panduan Penggunaan SITEDI sebagai dokumentasi operasional untuk membantu pengguna memahami alur, fungsi, dan penggunaan fitur pada sistem.

## Interactive Prototyping

Interactive prototype digunakan untuk memvisualisasikan bagaimana pengguna berinteraksi dengan sistem sebelum tahap implementasi.

Prototype membantu menggambarkan:

- Struktur halaman.
- Alur pengguna.
- Navigasi.
- Hubungan antar bagian sistem.
- Layout antarmuka.
- Pola interaksi.

Prototype juga digunakan sebagai media komunikasi antara rancangan kebutuhan pengguna dan Tim Developer IT.

## Information Architecture

Perancangan antarmuka memperhatikan struktur informasi agar fungsi dan konten sistem dapat disusun secara terarah.

Area yang diperhatikan meliputi:

- Pengelompokan informasi.
- Struktur halaman.
- Navigasi.
- User flow.
- Hubungan antar fitur.
- Konsistensi penyajian informasi.

## User Flow

User flow digunakan untuk menggambarkan langkah pengguna ketika mengoperasikan sistem.

Perancangan alur membantu memvisualisasikan hubungan antar halaman dan proses interaksi sebelum sistem dikembangkan lebih lanjut.

## Design Consistency

Dalam proses perancangan, konsistensi antarmuka diterapkan pada beberapa aspek:

- Layout.
- Navigasi.
- Struktur informasi.
- Pola interaksi.
- Hubungan antar halaman.

Tujuannya adalah menjaga agar pengalaman penggunaan tetap terarah dan mudah dipahami.

## Design Communication

Prototype digunakan sebagai media komunikasi desain antara kebutuhan pengguna dan Tim Developer IT.

Melalui prototype, alur dan rancangan sistem dapat divisualisasikan sebelum tahap pengembangan lebih lanjut.

Hal yang dapat dikomunikasikan melalui prototype mencakup:

- Layout.
- Pola interaksi.
- Hubungan antar bagian sistem.
