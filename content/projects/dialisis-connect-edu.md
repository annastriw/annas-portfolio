# Dialisis Connect Edu

## Project Snapshot

- **Nama Project:** Dialisis Connect Edu
- **Jenis Project:** Fullstack Web Application / Health Education / Community Platform
- **Peran:** Fullstack Developer
- **Stakeholder:** Ikatan Perawat Dialisis Indonesia (IPDI) Jawa Tengah
- **UI/UX Design:** Figma
- **Frontend:** Next.js
- **Backend:** Laravel
- **Database:** MySQL
- **Quality Assurance:** Katalon Studio
- **Testing:** Manual Testing dan Automation Testing
- **Deployment:** Docker pada Linux Ubuntu
- **Main Users:** Pasien, Tenaga Kesehatan, dan Administrator

## Ringkasan Project

Dialisis Connect Edu merupakan platform edukasi dan komunitas digital yang dikembangkan untuk pasien hemodialisis, keluarga, tenaga kesehatan, dan masyarakat yang membutuhkan informasi terkait terapi pengganti ginjal.

Project dikembangkan secara end-to-end sebagai Fullstack Developer, mulai dari perancangan UI/UX menggunakan Figma, frontend development menggunakan Next.js, backend development menggunakan Laravel, pengelolaan database MySQL, Quality Assurance menggunakan Katalon Studio, hingga containerization dan deployment menggunakan Docker pada Linux Ubuntu.

Platform menyediakan konten edukasi, video YouTube, preview PDF booklet, dan forum diskusi sebagai bagian dari sarana edukasi dan interaksi pengguna.

Sistem memiliki tiga role utama, yaitu Pasien, Tenaga Kesehatan, dan Administrator.

Pengembangan dilakukan dengan melibatkan Ikatan Perawat Dialisis Indonesia (IPDI) Jawa Tengah sebagai stakeholder.
